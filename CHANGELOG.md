# CAELIX changelog

## 0.1.33 — Beat-the-flagship kit: tiered routing, edit diagnostics, mid-turn steering, and team review

- **Tiered model routing (`src/engine/providers.js`, `src/engine/index.js`):** Auxiliary work no longer burns the chat's heavy model. Read-only research subagents and AI chat titles now run on each provider's fast, high-quota model (`gemini-3.5-flash-lite`, Groq `qwen/qwen3.8-27b`, NVIDIA `nemotron-3.5-lightning-30b-a3b`, Coarena `gemini-3-8-flash`, Numes `z-ai/glm-5.3`, OpenRouter `openrouter/free`) via `MODEL_ROUTING`/`auxiliaryModel()`, while planning, coding edits and final answers keep the session model. Providers without a routing entry keep the session model.
- **Automatic diagnostics after every write/edit (`src/engine/diagnostics.js`, `src/engine/tools.js`):** `write_file`, `edit_file` and `multi_edit` results now include instant read-only syntax checks — `node --check` for JS, `python3 -m py_compile` for Python, `JSON.parse` for JSON — so a model learns immediately when its edit broke something instead of discovering it turns later. Clean files add nothing to the output; missing checker binaries are skipped silently.
- **Mid-turn steering (`src/engine/index.js`, `src/renderer/app.js`):** Messages typed while a reply is running are no longer rejected. The engine queues them (`steering-queued` event) and injects them at the next round boundary (`steering-applied`), so a correction lands before the model's next tool call. If the turn ends before draining, leftovers are persisted into the chat history (`steering-flushed`) so words are never dropped. The renderer's `state.streaming` guard now allows sending during a run.
- **Team review — a second brain checks every edit (`src/engine/index.js`, `src/cli.js`):** New `--review` CLI flag / `session.review` runs an automatic post-turn pass where an independent model from a *different provider family* reviews the changed files with fresh eyes, fixes bugs, and proves the result. Benchmark-proven on a 3-task hard set (Roman-numeral round-trips 1..3999, N-Queens counts n=6/9/11, subtle binary-search `lo < hi` bug — each verified against independently computed ground truth, `checks/bench-hard.js`): solo free brains scored **4/6** (both Groq and Gemini failed the binary-search fix), while the team scored **6/6** — matching Claude Sonnet 5.5's **3/3** (11–15 s per task, tested through claude.ai) at $0 cost.
- **Verified:** `checks/verify_features.js` now has **37 checks** — diagnostics flag broken JS and stay silent on clean files, routing table maps providers to fast models, steering queues and injects, and team review picks a cross-family reviewer, runs once without recursion and restores the session. In-tree `npm run selfcheck` passes (28 steps, 0 errors).

Also deferred hidden `read_file` image carrier user messages in `Engine.send()` until after the entire `assistant.toolCalls` loop finishes so multi-tool turns remain contiguous.
