Keys

          
Paste a provider key. It is encrypted with the macOS keychain, stored outside this project and shown only as a mask.

        

      

      

      

        
        Keys are never written to logs, screenshots or Git.
      

    

  


  

    

      
      

        
        

          
Project memory

          
Instructions saved in this folder. They are added to every reply, and @file lines import another file inside the project.

        

      

      

        
        
      

      
      

      

        
        Memory stays in this project folder.
        
      

    

  


  

    

      
      

        
        

          
MCP Servers

          
Connect stdio or HTTP Model Context Protocol servers. Discovered tools are prefixed with mcp__ and obey your permission mode.

        

      

      

      

        
        
        
        
      

      

        

          
          
        

        

          
          
        

      

      

        Configs are read from .mcp.json and user mcp.json.
        
      

    

  


  

    

      
      

        
        

          
Lifecycle Hooks

          
Run shell commands on tool or prompt events. Hooks receive JSON on stdin; exit code 2 blocks the action.

        

      

      

      

        
        
        
      

      

        

          
          
          
        

        

          
          
        

      

      

        Hooks run with CAELIX_HOOK_EVENT and CAELIX_PROJECT_DIR set.
